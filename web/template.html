ada-ai-amplifier

Readable AI building blocks in plain Ada. The parts that run in the browser are compiled from that Ada to WebAssembly. The splash is a picture of that idea: points and weights flow into a small network. Ada computes every position. JavaScript only draws.

The network in the splash is a drawing. It is not trained.

Tensor demo

Edit the matrix and the vector, then Compute. Ada multiplies them and runs softmax on the product. JavaScript only passes the numbers. The shapes are 3 and 3, so the shape checks pass. This is plain Ada, not a proved kernel, and it is not a trained network.

Train a small network

Two inputs, eight tanh units, one sigmoid output. Ada initializes the weights from a fixed seed, then runs the forward pass, binary cross-entropy, and gradient descent. JavaScript draws the loss and the decision boundary. It does not train. The splash above is still only a drawing.

Gold is class 1, blue is class 0. The heat is the network's probability. Eight hidden units separate XOR and the two circles. The spirals are a harder cut: the loss falls, and the boundary stays a rough one.

Tokens and attention

Type in the box. JavaScript sends the UTF-8 bytes. Ada learns a small byte-level vocabulary from a public-domain excerpt, splits the text into those pieces, and runs one causal attention block. The colours and the heatmap are a drawing of what Ada returned. The block is not trained. Its weights are a fixed seed.

Waiting for the Ada module.

Each chip is one token, with its id. A gold cell is the weight that token gives an earlier one, including itself. Dark cells are the future, and the mask sets them to zero. A row adds up to one. In this vocabulary ß is one learned piece and ä is still two bytes.

On this page

  • Tap the splash, or press Enter, to leave it.
  • The tensor demo asks Ada for a matrix-vector product and a softmax.
  • Train runs the small network. Reset restores the seeded weights. The learning rate is Ada's step size.
  • The text box asks Ada to tokenize and to run attention. JavaScript only paints.
  • F9, or Feedback, writes a feedback file.
  • If the previous session did not end cleanly, a crash report is offered.
