v0.2.0-splash

ada-ai-amplifier

Readable AI building blocks in plain Ada. The parts that run in the browser are compiled from that Ada to WebAssembly. The splash is a picture of that idea: points and weights flow into a small network. Ada computes every position. JavaScript only draws.

The network in the splash is a drawing. It is not trained.

On this page

  • Tap the splash, or press Enter, to leave it.
  • F9, or Feedback, writes a feedback file.
  • If the previous session did not end cleanly, a crash report is offered.
